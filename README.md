# Русская озвучка — Lara Croft and the Temple of Osiris

Полная русская озвучка игры: **982 реплики из 983**, 45,7 минуты речи, шесть
голосов. Ставится патчем, который не трогает ни одного байта за пределами
звуковых данных: таблица архива, субтитры, cue-записи движка и размеры записей
остаются прежними.

> **Озвучка синтезированная, а не студийная.** Это машинный голос: интонация
> ровная, эмоций нет, в спешных местах речь заметно ускорена. Если вы ждёте
> уровня официального дубляжа — этого здесь нет и не планировалось.
> Смысл проекта в другом: официальный русский текст всех реплик уже лежит
> в файлах игры, а озвучки к нему не было никогда.

Проверено прохождением: игра стабильна, вылетов нет.

## Установка

1. Скачайте архив из [Releases](../../releases).
2. Распакуйте куда угодно.
3. Запустите **`Установить озвучку.bat`**.

Больше ничего не нужно — ни Python, ни ffmpeg, ни распаковщиков: установщик
работает на том PowerShell, который уже есть в Windows. Папку игры он ищет сам;
если не нашёл — спросит путь (там, где лежат `LC2.exe` и
`bigfile_ENGLISH.000.tiger`).

Перед установкой рядом создаётся резервная копия `bigfile_ENGLISH.000.tiger.bak`
— **не удаляйте её**. Откат: `Вернуть английскую.bat`.

Патч собран на файле с контрольной суммой
`959b8ede228471f10cbee111bbe5dc007f5823866e2201c5dd9136615aca5fd5`. Если у вас
другая сборка, установщик предупредит и предложит попробовать всё равно:
реплики он ищет по хешам записей в таблице архива, а не по смещениям в файле,
поэтому при другой раскладке архива патч, скорее всего, всё равно встанет.
Каждая запись проверяется отдельно, и если не подошла ни одна — файл не
изменяется вовсе.

Список честный, по цифрам финальной сборки:

| Звучат «наполовину по-английски» | 93 — русская фраза кладётся в начало слота, а в оригинале речь начинается позже, и её хвост слышен |
| Ускорено ощутимо (1,2–1,5×) | 105 |
| Ускорено сильно (1,5–2,2×) | 24 |
| Скороговорка (>2,2×) | 4 |
| Обрезано | 0 |
| Тише оригинала (усиление на пределе) | 139 |

Кроме того:

- **Ролики `LC2Intro.bik` и `LC2Outro.bik` — английские.** Звук вшит в контейнер
  Bink 1; заменить его без перекодирования 300 МБ видео нельзя. Русские субтитры
  к обоим роликам в игре есть.
- **Липсинк в катсценах анимирован под английскую речь** — это не исправляется
  подменой звука в принципе.
- Голоса — публичные модели из библиотеки fish.audio, а **не клоны оригинальных
  актёров**. Оригинальные английские дорожки использовались только как эталон
  громкости и длительности.

## Как это устроено

Техническая часть — в [`docs/`](docs/), там два отчёта целиком.
Коротко то, ради чего стоит смотреть код:

Реплика в `bigfile_ENGLISH.000.tiger` (архив TAFS v4) лежит не сплошным
MP3-потоком. Поток разбит на **чанки** (16 байт заголовка: размер, номер потока,
8 байт магии `CD`), между чанками движок держит 32-байтные cue-записи, а внутри
чанка каждый MPEG-кадр сидит в **своём 316-байтном слоте** с нулевым хвостом
(316 = максимальный кадр 96 кбит/с при 44,1 кГц, выровненный на 4; флаг банка
`0x40` = `FSOUND_FSB_SOURCE_MPEG_PADDED4`). Поток продолжается за границей
`dataSize` — до конца записи архива.

Отсюда жёсткое требование, на котором ломались все ранние попытки:
**`main_data_begin` должен быть нулём у каждого кадра**. LAME по умолчанию
пользуется бит-резервуаром и переносит часть данных кадра в предыдущий; в
раскладке по слотам, где между кадрами стоят нули и заголовки чанков, такой
поток рассыпается в мусор. Лечится одним флагом — `ffmpeg -reservoir 0`.

Пересобирать банк FSB4 не требуется: заголовки в архиве уже правильные, менять
надо только байты кадров внутри существующих слотов. Проверено на всех 983
записях — число кадров всегда равно `lengthSamples / 1152` и
`lengthCompressed / 316`, расхождений 0.

Для проверки использовалась **родная `fmodex.dll` игры** (FMOD Ex 4.33.9),
вызываемая из 32-битного PowerShell (`tools/oracle.ps1`): банк-кандидат
декодируется тем же кодом, что и в игре, без запуска игры.

Всё это, скорее всего, применимо к другим играм Crystal Dynamics на TAFS/FSB4.

## Состав репозитория

```
patcher/   makepatch.py   сборка патча из пары «оригинал + пропатченный архив»
           install.ps1    установщик: разбор TAFS, применение, проверки, откат
tools/     mul.py         разбор потока: чанки, слоты, оба стереопотока
           dub.py         синтез -> тримминг -> громкость и темп -> MP3 -> слоты
           apply.py       вшивание в архив (всегда от .bak)
           audit.py       проверка модели формата на всех записях
           verify_patch.py сверка патча с резервом
           oracle.ps1     декодирование банка родной FMOD игры
           fish.py        клиент fish.audio (ключ — в FISH_API_KEY)
docs/      два технических отчёта
```

Конвейер синтеза запускается так:

```
set LC2_GAME=D:\Games\Lara Croft - Temple of Osiris\Game
set FISH_API_KEY=...
python tools/build.py       # синтез реплик
python tools/apply.py --all # вшить всё
python tools/apply.py --restore
```

**Сборка не воспроизводима, и это осознанно.** `apply.py --all` берёт реплики
из каталога `vo_wav/` — 274 МБ синтезированных WAV, которым в репозитории не
место. Запуск `build.py` заново синтезирует все 982 реплики через ваш ключ
fish.audio, и результат будет другим: у модели нет фиксированного зерна.
`tools/` — это запись метода и разбор формата, а не воспроизводимый билд;
для установки готовой озвучки он не нужен вовсе.

## Правовая заметка

В патче нет ни одного байта оригинальной игры — только синтезированная речь
и смещения, по которым её класть. Игру он не распространяет и не обходит защиту:
это модификация уже установленной легальной копии. Lara Croft and the Temple of
